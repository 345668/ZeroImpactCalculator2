5️⃣ Backend: Sending an Email
🟢 Python (Flask Example)
python
Copy
Edit
import os
from sendgrid import SendGridAPIClient
from sendgrid.helpers.mail import Mail
from flask import Flask, request, jsonify

app = Flask(__name__)

SENDGRID_API_KEY = "YOUR_SENDGRID_API_KEY"

@app.route("/send-email", methods=["POST"])
def send_email():
    data = request.get_json()
    message = Mail(
        from_email="your_verified_email@example.com",  # Verified sender
        to_emails=data["recipient"],  # Get recipient from the request
        subject=data["subject"],
        plain_text_content=data["message"]
    )
    
    try:
        sg = SendGridAPIClient(SENDGRID_API_KEY)
        response = sg.send(message)
        return jsonify({"status": "Email Sent", "code": response.status_code})
    except Exception as e:
        return jsonify({"status": "Error", "message": str(e)}), 500

if __name__ == "__main__":
    app.run(debug=True)
🔹 How it works:

API endpoint /send-email receives email details as JSON.
Extracts recipient, subject, and message from the request.
Uses SendGrid API to send the email.
Returns a response confirming whether the email was sent.

const express = require("express");
const sgMail = require("@sendgrid/mail");

const app = express();
sgMail.setApiKey("YOUR_SENDGRID_API_KEY");

app.use(express.json());

app.post("/send-email", async (req, res) => {
    const { recipient, subject, message } = req.body;
    
    const msg = {
        to: recipient,
        from: "your_verified_email@example.com", 
        subject: subject,
        text: message,
    };

    try {
        await sgMail.send(msg);
        res.json({ status: "Email Sent" });
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

app.listen(3000, () => console.log("Server running on port 3000"));

7️⃣ Webhook (Tracking Email Events)
To track delivery status, you can enable SendGrid Event Webhooks.

Go to SendGrid Dashboard → Settings → Event Webhook
Enable events like:
delivered
opened
bounced
spam reports
Set a webhook URL (e.g., http://yourserver.com/webhook).

8️⃣ Handling Common Issues
❌ Emails Going to Spam?
Use a verified sender (Domain Authentication in SendGrid)
Add SPF, DKIM, and DMARC records to your domain.
Avoid spammy words like Free, Discount, Click Here.
❌ Not Receiving Emails?
Check SendGrid Activity Logs for errors.
Ensure your recipient email isn't on the suppression list (Blocks/Bounces in SendGrid).
Verify that your API key has "Mail Send" permissions.
❌ Rate Limits
Free-tier accounts are limited to 100 emails/day.
Consider upgrading to a paid plan if you need more.
9️⃣ Summary: How Data is Processed
User Input (Frontend)

User submits an email form.
JavaScript sends data via fetch() or Axios.
Backend Processing (Flask, Express, etc.)

Receives email request.
Parses recipient, subject, message.
Calls SendGrid API to send the email.
SendGrid Processing

Validates API key and sender email.
Sends the email.
Updates status (delivered, bounced, spam, etc.).
Recipient Interaction

User receives email.
Can reply, click, or mark as spam.
Event Tracking (Optional)

Webhook sends email status updates to the backend.
🚀 Final Thoughts
✅ Secure your API key (never expose it in frontend code).
✅ Use verified sender domains for better email delivery.
✅ Monitor activity logs to debug any issues.
